# 기능: 삭제 가능 표시와 크기 기억

## 삭제 가능 표시
- 폴더 행을 우클릭 → "삭제해도 되는 폴더로 표시 (이 앱에만 기록)". 해제는 같은 자리의 "삭제 가능 표시 해제".
- **표시만** 한다. 파일은 지우거나 옮기지 않고, 폴더 안에 표시 파일도 만들지 않는다.
- 기록은 `%APPDATA%\FolderSizeViewer\marks.txt` 에 경로로 저장된다(한 줄에 하나, 메모장으로 열어 볼 수 있다).
- 폴더가 삭제돼도 기록은 남아 있어, 같은 경로에 같은 이름의 폴더가 다시 생기면 자동으로 "삭제 가능"으로 보인다. 경로 비교는 대소문자를 구분하지 않는다.
- 표시한 폴더의 하위 폴더는 "상위 폴더가 삭제 가능"으로 흐리게 보이며 따로 표시할 수 없다. 드라이브 루트는 표시할 수 없다.
- 하단 상태 줄에 현재 화면의 표시 폴더 개수와 합계 용량이 보인다(계산 중인 폴더는 빼고 "(계산 중)"이라고 알린다).

- 맨 위 **"삭제 가능" 메뉴**에 표시한 폴더가 모두 나열된다. 누르면 그 폴더로 들어간다 (자세히: `menu-bar.md`).

## 크기 기억
- 폴더 크기를 계산할 때마다 `%APPDATA%\FolderSizeViewer\sizes.txt` 에 (경로, 바이트, 계산 시각)을 저장한다.
- 폴더를 열면 기억한 크기가 **흐리게** 즉시 나오고, 뒤에서 다시 계산이 끝나면 정확한 값으로 바뀌며 선명해진다.
- 폴더의 "수정 시각"은 그 폴더 바로 아래 항목이 바뀔 때만 변하고 더 깊은 곳의 변화는 반영되지 않기 때문에, 수정 시각만 보고 재계산을 건너뛰지 않는다.
- 90일 넘게 다시 계산되지 않은 기억은 지운다.

## 용어
- 원자적 저장: 임시 파일에 먼저 쓰고 한 번에 바꿔치기해서, 도중에 꺼져도 기존 기록이 깨지지 않게 하는 방식.
- 시험용 환경변수: `FOLDERSIZEVIEWER_MARKS_FILE`, `FOLDERSIZEVIEWER_SIZES_FILE` 로 기록 파일 경로를 바꿀 수 있다(실제 기록을 건드리지 않고 시험할 때).
