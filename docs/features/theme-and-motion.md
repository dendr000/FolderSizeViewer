# 기능: 라이트/다크 테마 & 모션

## 테마 (`Theme.cs`)

- 실행 시 레지스트리 `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize` 의
  `AppsUseLightTheme` 값을 읽어 시스템이 다크 모드인지 자동 감지하고, 그 값을 초기 테마로 쓴다.
- 툴바의 해/달 아이콘 버튼으로 언제든 수동 전환할 수 있다.
- **구현 방식**: 색상마다 하나씩 `SolidColorBrush` 인스턴스를 만들어 두고, 모든 UI 요소가
  그 **같은 인스턴스**를 `Background`/`Foreground`/`BorderBrush`로 참조하게 한다. 테마를 바꿀 때는
  새 브러시를 만들어 교체하는 게 아니라, 기존 브러시 인스턴스의 `Color` 프로퍼티를
  `ColorAnimation`으로 애니메이션시킨다. 브러시는 참조 타입이라 이 방식으로 **화면 전체가 한 번에
  부드럽게 크로스페이드**된다 — 요소 하나하나를 따로 애니메이션시킬 필요가 없다.

## 모션

| 상황 | 효과 |
|---|---|
| 폴더 이동(목록 내용이 바뀜) | 목록 영역이 투명(0)에서 불투명(1)으로 200ms 페이드인 |
| 폴더 크기 계산 중 | 상태 표시줄의 새로고침 아이콘이 1초 주기로 계속 회전 |
| 테마 전환 버튼 클릭 | 해/달 아이콘이 짧게 페이드아웃 → 바뀐 아이콘으로 교체 → 페이드인 |
| 테마 전환 전체 | 위 "테마" 항목의 색상 크로스페이드 (260ms) |

## UI 아이콘

아이콘은 `assets/icons/*.svg` 파일로 따로 저장하고, `SvgIcon.cs`(직접 만든 최소 SVG 파서)가
`<path>`/`<circle>`/`<rect>` 와 `rotate(...)` 변환만 지원해서 읽어온다. 범용 SVG 렌더러가 아니라
**이 앱의 아이콘 8개를 그리는 데 필요한 만큼만** 구현한 것이다. 색은 SVG의 `fill="currentColor"`
자리에 테마 브러시를 흘려 넣는 방식으로 입혀서, 아이콘도 테마 전환에 맞춰 같이 바뀐다.

NuGet/프로젝트 파일 없이 `csc.exe`만으로 빌드하는 제약 때문에 SVG를 실제 렌더링 라이브러리
없이 직접 파싱해야 했다 — `SvgIcon.cs` 상단 주석에 이 제약을 적어 두었다.
