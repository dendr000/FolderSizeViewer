# 기능: 상단 메뉴 바와 단축키

공용 지침(`guides\menu-bar.md`)에 따라 기능이 여럿이라 메뉴 바를 넣었다. 메뉴 항목은 툴바 버튼과 같은 함수를 부른다.

| 메뉴 | 항목 (단축키) |
|---|---|
| 파일 | 폴더 열기 (Ctrl+O), 현재 폴더를 탐색기에서 열기, 새로고침 (F5), 종료 (Alt+F4) |
| 보기 | 위 폴더로 (Alt+위), 드라이브 목록, 라이트/다크 전환 (Ctrl+T) |
| 삭제 가능 | 표시한 폴더 목록 (아래 설명) |
| 설정 | 표시·크기 기록 폴더 열기, 저장된 폴더 크기 지우기 |
| 도움말 | 단축키, 폴더 크기 보기 정보 (버전) |

## "삭제 가능" 메뉴 (즐겨찾기처럼 쓰기)
- 표시가 많아져도 메뉴가 길어지지 않도록 **지금 있는 폴더 중 기억된 크기가 큰 순서 상위 10개**만 보여 준다. 각 줄은 경로와 오른쪽에 기억된 크기.
- 폴더 존재 확인은 메뉴를 열 때 최대 0.3초만 쓴다(연결 안 된 네트워크 경로로 멈추지 않게).
- 맨 아래 "전체 목록 보기 / 검색... (Ctrl+D)" 로 전체 목록 창을 연다.
- 항목을 누르면 그 폴더 안으로 들어가고, 하단에 "이 폴더는 삭제 가능으로 표시됨"이 보인다.
- 크기는 "저장된 폴더 크기"(마지막으로 계산했을 때의 값)이므로, 정확한 값은 폴더를 열어 다시 계산되면 갱신된다.

## 전체 목록 창 (Ctrl+D)
- 모든 표시 폴더를 한 화면에서 본다. 위쪽 입력칸에 경로 일부를 치면 걸러진다.
- 정렬: 지금 있는 폴더가 먼저, 그 안에서 기억된 크기가 큰 순서. 없는 폴더는 맨 아래에 "없음"으로 보인다.
- 버튼: **이동**(더블클릭, Enter), **탐색기에서 열기**, **표시 해제**. 없는 폴더는 이동·열기가 되지 않는다.
- 맨 아래에 "N개 표시 / 전체 M개 (지금 있는 것 K개) - 기억된 크기 합계"가 보인다. 합계는 지금 있는 폴더만 더하고, 상위 폴더가 이미 표시된 하위 폴더는 뺀다.
- 창이 열려 있는 동안 메인 화면에서 표시·해제를 하면 목록이 같이 갱신된다.
- 폴더 존재 확인은 뒤에서(백그라운드) 해서 수백 개여도 화면이 멈추지 않는다.

## 메뉴 모양
기본 WPF 메뉴는 어두운 테마에서도 흰 상자로 보이므로 `MenuStyles.cs` 가 메뉴·드롭다운·우클릭 메뉴를 앱 테마 색으로 직접 그린다.
