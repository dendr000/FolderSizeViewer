# 기능: 앱 아이콘

- 원본은 `assets/app.ico` (16·24·32·48·64·128·256px 전부 포함, 256px은 PNG 압축). 파란 둥근 사각형 안에 흰 폴더와 크기 막대 세 줄.
- `build.ps1` 이 `csc /win32icon` 으로 exe 파일 자체에 넣는다. 그래서 탐색기, 바로가기, 런처 앱 같은 곳이 exe 의 아이콘을 읽어 보여 준다.
- 창(제목 표시줄, 작업 표시줄)에는 `MainWindow.ApplyWindowIcon()` 이 exe 에 들어간 아이콘을 읽어 적용한다.
- 모양을 바꾸려면 `tools/make-icon.ps1` 을 고쳐 실행해 `assets/app.ico` 를 다시 만들고 `build.ps1` 로 다시 빌드한다.
- Windows 는 아이콘을 캐시해 두기 때문에, 이미 만들어 둔 바로가기나 작업 표시줄 고정은 옛 아이콘을 한동안 들고 있을 수 있다. 고정을 풀었다가 새 exe 로 다시 고정하면 바뀐다.
