# 폴더 크기 보기 (FolderSizeViewer) — 계획서

## 목표

탐색기에서 폴더 크기가 보이지 않는 문제를 해결한다. 파일은 "크기" 컬럼에 바로 보이지만
폴더는 하위 파일을 전부 더한 크기가 표시되지 않는 Windows의 기본 동작을 보완하는 도구를 만든다.

## 기술 조사 결과 (왜 이 방식을 선택했는가)

처음에는 탐색기 자체의 "크기" 컬럼에 완전히 통합하는 방식(셸 확장)을 시도했다.

1. **`IColumnProvider` (Column Handler)** — 탐색기에 새 컬럼을 추가하는 고전 COM 방식.
   구현 후 등록까지 마쳤으나, Microsoft 공식 문서(`learn.microsoft.com/.../lwef/column-handlers`)에
   **"Windows XP 이하에서만 지원됨"**이라고 명시되어 있음을 확인. Vista 이후 완전히 제거된 API라
   최신 탐색기는 이 레지스트리 경로를 아예 조회하지 않는다 (직접 COM 활성화 테스트로는
   정상 동작했지만 탐색기 프로세스가 DLL을 로드조차 하지 않음을 확인).
2. **Windows Property System (`IPropertyStore` + `.propdesc` 스키마)** — Vista 이후 공식 대체 수단.
   원리상 `HKCR\Folder\shellex\PropertyHandler`에 등록 가능하나, 파일 형식(음악·사진)에는 검증된
   사례가 많은 반면 **폴더 자체**에 대해 탐색기가 실제로 호출해준다는 확실한 근거를 찾지 못함.
   구현 난이도(속성 스키마 등록 + `PSRegisterPropertySchema` 호출)에 비해 실패 위험이 커서 보류.

→ 사용자와 상의 후, **탐색기 내부 통합은 포기**하고 **독립 실행형 프로그램**으로 방향을 바꿈.
(참고: `C:\dev\FolderSizeColumn` 에 XP 전용으로 확인된 IColumnProvider 실험 코드가 그대로 남아있음 —
동작하지 않으므로 재사용하지 말 것. 레지스트리에도 등록되어 있으나 탐색기가 로드하지 않아 무해함.)

## 최종 아키텍처

- **WPF (.NET Framework, C# 5)** — 탐색기 대체용 미니 파일 매니저.
  - 처음엔 WinForms로 시작했으나, 사용자가 라이트/다크 테마와 애니메이션을 요청하면서
    벡터 렌더링과 Storyboard 애니메이션을 기본 지원하는 **WPF로 전환**.
  - Visual Studio나 .NET SDK 설치 없이, OS에 이미 포함된 `csc.exe`(.NET Framework 4 컴파일러,
    `C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe`)만으로 빌드.
    → **C# 5 문법 제약**: `?.`, 패턴 매칭, 문자열 보간, 자동 프로퍼티 초기화자 등 최신 문법 사용 불가.
  - XAML/BAML 컴파일러(MSBuild WPF 타깃) 없이 빌드해야 하므로 **UI를 XAML 없이 전부 C# 코드로 구성**
    (`FrameworkElementFactory` 기반 `ControlTemplate`/`DataTemplate`).

## 기능 범위

- 드라이브 목록 → 폴더 탐색 → 상위 폴더로 이동, 경로 직접 입력, 찾아보기 대화상자.
- 폴더는 하위 전체를 재귀적으로 더한 크기를 백그라운드 스레드에서 계산 (UI 안 멈춤, 취소 가능).
- 파일/폴더 이름, 종류, 크기 기준 정렬. 크기 컬럼에 상대적 크기를 보여주는 막대 표시.
- 우클릭 → 탐색기에서 열기. 더블클릭 → 폴더 진입 / 파일은 기본 프로그램으로 열기.
- **의도적으로 제외**: 삭제·이동 등 파일 관리 기능. 이 도구는 "보기" 전용으로 범위를 한정한다
  (요청받지 않은 파괴적 기능을 넣지 않기 위함).

## 디자인 방향 (사용자 요청: "디자인 신경 써서, 라이트/다크, 애니메이션")

- **테마**: 실행 시 레지스트리(`HKCU\...\Personalize\AppsUseLightTheme`)로 시스템 라이트/다크 설정을
  감지해 초기값으로 사용. 툴바의 해/달 아이콘 버튼으로 수동 전환 가능.
  전환 시 모든 색상이 공유되는 `SolidColorBrush` 인스턴스의 `Color` 프로퍼티를 애니메이션시켜
  전체 UI가 부드럽게 크로스페이드 되도록 구현 (`Theme.cs`).
- **모션**: 폴더 이동 시 목록 페이드인, 크기 계산 중 상태 표시줄 스피너 회전, 테마 아이콘 전환 시
  페이드 교차.
- **비주얼**: 라운드 코너 버튼/카드, 플랫 리스트(그리드라인 제거, 호버·선택 시 배경색만 부드럽게
  변경), 크기 컬럼에 상대 크기 막대바 추가.

## 남은 선택지 / 향후 고려사항

- 아이콘은 실제 파일 확장자별 아이콘이 아니라 폴더/파일 2종 심플 아이콘으로 단순화함 (범위 축소).
- 코드 서명을 하지 않음 — 첫 실행 시 SmartScreen 경고가 뜰 수 있음 (Saegim 프로젝트와 동일한 방침).
- `C:\dev\FolderSizeColumn`(레거시 IColumnProvider 실험)은 등록된 채로 남아있으나 탐색기가
  로드하지 않아 무해함. 원하면 `unregister.ps1` 실행 후 폴더 삭제 가능.
