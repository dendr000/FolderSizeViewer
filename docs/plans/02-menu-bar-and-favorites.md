# 계획서 02: 상단 메뉴 바와 삭제 가능 폴더 바로가기

## 목표
- "삭제 가능"으로 표시한 폴더를 즐겨찾기처럼 한 번에 찾아 들어간다.
- 공용 지침(`guides\menu-bar.md`)에 따라 상단 메뉴 바를 둔다.

## 설계와 결정
- **메뉴 바를 넣는다.** 이유: 폴더 열기·새로고침·테마·표시 목록·설정·도움말 등 기능이 여럿이고 단축키를 함께 쓴다.
- 메뉴: 파일(폴더 열기 Ctrl+O, 현재 폴더 탐색기에서 열기, 새로고침 F5, 종료) / 보기(위 폴더로 Alt+위, 드라이브 목록, 라이트/다크 전환 Ctrl+T) / **삭제 가능**(표시한 폴더 목록) / 설정(기록 폴더 열기, 크기 기억 지우기) / 도움말(단축키, 정보).
- "삭제 가능" 메뉴는 열 때마다 새로 만들며, 표시가 수백 개로 늘 수 있으므로 지금 있는 폴더 중 기억된 크기가 큰 상위 10개만 보인다. 전체는 검색되는 목록 창(Ctrl+D)에서 보고, 이동·탐색기 열기·표시 해제를 한다.
- 폴더 존재 확인은 메뉴에서는 0.3초 제한, 목록 창에서는 백그라운드로 해서 UI 가 멈추지 않게 한다.
- 합계는 지금 있는 폴더만, 상위 폴더가 이미 표시된 하위 폴더는 빼서 이중 계산하지 않는다.
- 메뉴·우클릭 메뉴가 어두운 테마에서 흰 상자로 보이지 않도록 메뉴 모양을 직접 그린다(`MenuStyles.cs`).
- 메뉴와 버튼은 같은 함수를 부른다.
- 버전은 `AssemblyInfo.cs` 에 두어 정보 창과 exe 파일 속성이 같은 값을 쓴다(CHANGELOG 최신 버전과 맞춘다).
