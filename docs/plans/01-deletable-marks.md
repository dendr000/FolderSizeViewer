# 계획서 01: 삭제 가능 표시와 크기 기억

## 목표
- PC 용량 정리용. 폴더에 "삭제해도 된다"고 판단했을 때 이 앱 안에서만 표시해 둔다.
- 크롬 캐시처럼 지워도 다시 쌓이는 폴더를 위해, 폴더가 사라져도 기록은 남고 같은 경로에 다시 생기면 자동 표시한다.
- 폴더 크기 계산이 오래 걸리므로 한 번 계산한 값을 기억해 바로 보여 준다.

## 설계와 결정
- 표시는 **경로 기준**으로 `%APPDATA%\FolderSizeViewer\marks.txt` 에 저장한다. 폴더 안에는 아무것도 쓰지 않는다. (사용자 결정)
- 상위 폴더가 표시돼 있으면 하위는 "상위 폴더가 삭제 가능"으로 흐리게 보이고 따로 표시하지 않는다.
- 드라이브 루트는 표시할 수 없다.
- 이 기능은 **표시만** 한다. 실제 삭제는 하지 않는다.
- 크기 기억은 `sizes.txt`(경로, 바이트, 계산 시각). 폴더의 수정 시각은 바로 아래 항목이 바뀔 때만 변하고 깊은 곳의 변화는 못 잡으므로, 수정 시각만 믿고 재계산을 건너뛰면 틀린 값이 나온다. 그래서 기억한 값을 흐리게 즉시 보여 주고 뒤에서 항상 다시 계산해 교체한다. 90일 지난 기억은 버린다.
- 저장은 임시 파일에 쓴 뒤 바꿔치기(원자적). 읽기에 실패하면 덮어쓰지 않는다.

## 단계
1. DeletableMarks / SizeCache 로직과 시험 (완료)
2. 우클릭 선택 버그 수정, 메뉴, 칩, 합계 표시 (완료)
3. 크기 기억 연결 (완료)
